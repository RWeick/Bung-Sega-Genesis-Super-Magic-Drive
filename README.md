# Bung-Sega-Genesis-Super-Magic-Drive
The bioses and Kicad files for the Bung Super Magic Drive for the Sega Genesis

PCB Thicknesses are documented in the Kicad files.

The motherboard contains two modifications from the original: a bodged resistor pack now has its own footprint and there is a solder jumper to switch between original 16M RAM mode and 32M RAM mode. The 32M RAM mode was a modification that would be done when you sent your system back to Bung for the upgrade. Unfortunately it appears that the upgrade also required the CPLD to be upgraded as well, and a modified CPLD has not yet surfaced to be studied. The upgrade solder jumper and 32M RAM board are therefore provided for a future point where the CPLD is found, studied, and reverse engineered. You may use a 32M RAM card with this system, but it will only register 16M of RAM.
